# 📱 React Phone Catalog

A modern **React** project showcasing a **catalog of phones** with interactive features.
Browse products, add to favorites, manage your cart, explore different product sections, and enjoy a clean, responsive design.

---

## 🔗 Demo

Check out the live demo:
👉 [React Phone Catalog](https://moddderi.github.io/Phone-Catalog/)

---

## 🛍 Features

- 🏷 **Browse Products** – View phones with images, descriptions, prices, and color variants
- ❤️ **Favorites** – Add or remove products to your favorites list
- 🛒 **Cart Management** – Add products to the cart, adjust quantity, remove items
- 🔍 **Product Filtering** – Filter by category, price, or color
- 🎨 **Color Variants** – Switch product color options dynamically
- 🏆 **Product Sections** – Sections like “Best Sellers”, “New Arrivals”, “Shop by Category”
- 📱 **Responsive Design** – Works perfectly on mobile, tablet, and desktop
- ♻️ **Reusable Components** – Header, Footer, Product Cards, Pagination, Dropdowns

---

## 🚀 Technologies Used

- **React**
- **TypeScript**
- **SCSS Modules**
- **Vite**
- **React Router**
- Custom Hooks for state management
